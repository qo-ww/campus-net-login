【第一步：一键安装（只需做一次）】

双击 setup.bat，等待安装完成。
如果提示没装 Python，会自动打开下载页面。

【第二步：修改配置（只需做一次）】

右键 配置.txt → 用记事本打开，改三行：

  学号 = 你的学号    ← 你的学号
  密码 = 你的学号    ← 你的密码
  运营商 = 电信            ← 电信/联通/移动/校园网

保存，关闭。

【第三步：一键启动】

双击 start.bat，选：
  [1] 能看到浏览器自动操作（推荐第一次用）
  [2] 后台静默运行

搞定！断网了会自动重连。

【开机自动启动（可选）】

右键 setup_autostart.bat → 以管理员身份运行。

【不想用了】

双击 stop.bat 即可停止。
